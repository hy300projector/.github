## HY300 Open Projector Project
This project aims to provide an alternative operating system for the HY300 Ultra projector free from malware and backdoors left in by the manufacturer. 

### Operating Systems
There are two operating system options available: 
- Mainline Linux (distro not chosen yet narrowed down to Libre Elec, Armbian, and PostmarketOS)
- Android AOSP TV 14 (Not LineageOS! LineageOS make files are provided however issues related to LineageOS will be closed as the authors only wish to officially support AOSP).
### Project Goals
The main goal of the project was to get a working system free from malware and bloatware that takes full advantage of the hardware.
### Contributions
Contributions are welcome and encouraged. Contributions to Android related repositories (including the Android 5.15 kernel) will follow AOSP contribution guidelines and Linux related repositories will follow Linux contribution guidelines.
